Homeme 隱私權政策

歡迎使用 Homeme 打卡系統。 為了提供會員打卡、排行榜與活動紀錄功能， 我們可能會蒐集部分必要資訊。

一、蒐集資訊

當您使用本服務時，我們可能會透過 LINE Login 取得：

  • LINE 顯示名稱
  • LINE 頭像
  • LINE 使用者識別碼（僅供系統辨識）
  • 打卡日期與次數紀錄

二、資訊用途

蒐集之資料僅用於：

  • 會員身份辨識
  • 打卡次數統計
  • 排行榜顯示
  • 活動與會員經營用途

三、資料保存

若超過180天未有任何打卡紀錄， 系統可能自動刪除相關資料。

四、第三方服務

本服務可能使用：

  • LINE Login
  • Supabase 雲端資料庫
  • GitHub Pages 網站服務

五、資料安全

我們將盡力保護您的個人資料安全， 並避免未經授權之存取。

六、聯絡方式

若有任何問題， 請透過 Homeme 官方 LINE 與我們聯繫。
